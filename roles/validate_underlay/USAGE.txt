EVPN-VXLAN Lab — Ansible Playbook Usage
========================================

Prerequisites
-------------
- clab running: sudo clab deploy -t clab_files/ceos_clos.yml
- Python venv active: source ~/automation/bin/activate
- All commands run from the project root: ~/labs/ceos_vxlan_evpn/

Credentials
-----------
Stored in secrets.yml (Ansible Vault, auto-unlocked via .vault_pass):
  - EOS nodes : admin / <vaulted>
  - Linux hosts: deployer / <vaulted>


VALIDATE BASE UNDERLAY (IS-IS + BGP EVPN)
------------------------------------------
Checks on every ceos node:
  1. IS-IS adjacencies — count and UP state
  2. BGP EVPN sessions — Established (spines + leaf1/2 only; leaf3/4/5 skip
     until a scenario playbook activates their EVPN address-family)
  3. Loopback reachability — pings all 7 fabric loopbacks from Loopback0

Run full validation (all 7 nodes):
  ansible-playbook playbooks/validate_underlay.yml

Run on a single node:
  ansible-playbook playbooks/validate_underlay.yml --limit spine1
  ansible-playbook playbooks/validate_underlay.yml --limit leaf1,leaf2

Verbose output (show assert messages inline):
  ansible-playbook playbooks/validate_underlay.yml -v

Expected PLAY RECAP (clean lab):
  spine1  ok=8  failed=0  skipped=0
  spine2  ok=8  failed=0  skipped=0
  leaf1   ok=8  failed=0  skipped=0
  leaf2   ok=8  failed=0  skipped=0
  leaf3   ok=5  failed=0  skipped=3   <- BGP EVPN skipped (no EVPN AF in base)
  leaf4   ok=5  failed=0  skipped=3
  leaf5   ok=5  failed=0  skipped=3
